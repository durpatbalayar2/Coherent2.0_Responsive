# Responsive Website Task – Cohort 2.0

This task is part of **Cohort 2.0**, focusing on building a **fully responsive website** using **HTML** and **SCSS**.  
The design and structure take inspiration from the [ALVY Studio Template](https://alvy-template.webflow.io/studio).

---

## 🧱 Tech Stack

- **HTML5** – For semantic structure and clean markup.
- **SCSS (Sass)** – For advanced CSS styling with variables, nesting, and mixins.
- **Flexbox** – Used for one-dimensional layouts and responsive alignment.
- **CSS Grid** – Used for complex two-dimensional section layouts.
- **Media Queries** – To ensure a fully responsive experience across devices (mobile, tablet, desktop).

---

## 🎯 Project Goals

- Create a **pixel-perfect layout** similar to the ALVY Studio template.
- Practice **modern CSS techniques** like Grid and Flexbox.
- Learn and apply **responsive design** principles.
- Build reusable and well-organized SCSS components.

---

## 💻 Features

- Responsive layout across mobile view, desktop view and 4K view.  
- Clean and modern UI inspired by a real-world Webflow design.  
- Organized SCSS structure for maintainability.  
- Use of Grid and Flexbox for different layout sections.
